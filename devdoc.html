Quickstart

Plug in Tokkey, pick a model and run it on your Mac. About five minutes.

5 minmacOS
On this page

  2. Plug in Tokkey
  3. Run your first model
  4. Connect your tools

Install the Tokkey app

Download the app for macOS and drag it to Applications. It lives in your menu bar.

Download for macOS

Plug in Tokkey

Connect Tokkey to a USB-C port. The menu bar icon turns green when it is ready.

You should see: “Tokkey connected” in the menu bar.

Run your first model

Pick a model that fits your Mac on the Models page, or run our suggestion from the terminal.

Terminal
$ tokkey run qwen3:8b
> Loaded on Tokkey · ready

Connect your tools

Use Tokkey as the model in Cursor, VS Code and other apps.

How Tokkey makes room

A model is split into parts. Tokkey holds all of them. Your Mac only holds the part it is using right now, runs it, then swaps in the next parts. See the diagram →

If something doesn’t work

The menu bar icon stays grey

Try another USB-C port and make sure the cable carries data. Then quit and reopen the app.

A model says “Too big”

Pick the 4-bit size, or a smaller model. The Models page shows what fits your Mac with Tokkey attached.
