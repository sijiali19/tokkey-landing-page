FAQ
Questions.
What is Tokkey?+
A USB-C Local AI Key with Tokkey Runtime and a local API. It works with your Mac. It is not a new computer.
Which Macs and models are supported?+
Apple silicon Macs. More memory lets you run larger models; the Software page has a table to check your Mac. Not every Mac or model is guaranteed.
Does it add a GPU, NPU, or RAM?+
No. Your Mac provides compute and working memory.
Does Tokkey include a chat interface?+
Yes, Private Chat. Compatible external tools can connect through the local API.
Is Agent Hub a new Tokkey agent?+
No. It is the entry point to connect and manage compatible agents.
What is shared Memory?+
Saved user context that you choose to share across tools. It is not RAM expansion.
Does Router keep every request local?+
No. Router lets you choose between local and cloud, and shows the model, shared excerpt and expected cost first.
Can a task continue with the lid closed?+
On supported configurations, yes. Photos are not proof.
Do I need the internet?+
Downloads, updates and cloud tasks need a connection. Installed local models work locally.
What do the performance numbers mean?+
Claims in the supplied artwork are not yet matched to reports. Treat them as placeholders until evidence is published.
How much will it cost?+
The planned one-time launch price is $129. Final pricing, availability and terms will be confirmed before orders open.
